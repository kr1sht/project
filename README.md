## Что умеет продукт сейчас

StudyCards находится на этапе проектирования и подготовки к разработке.

На данный момент подготовлены описание проекта, структура репозитория, документация и доска для управления задачами.

Планируемые возможности продукта:

- Создание учебных карточек из структурированных конспектов.
- Формирование карточек в формате «вопрос - ответ».
- Просмотр и повторение созданных карточек.

Эти функции пока являются планами разработки и не считаются реализованными до их фактического создания и проверки.

## Definition of Done

Задача считается выполненной, если:

- Реализован требуемый результат.
- Выполнены критерии приёмки.
- Проведена проверка работоспособности.
- Не осталось известных критических ошибок.
- Документация обновлена при необходимости.
- Результат добавлен в проект, а задача переведена в статус Done.
